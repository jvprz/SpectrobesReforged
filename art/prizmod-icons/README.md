# Prizmod portraits

Original hand-authored 16×16 drawings restored, with three color variants per species. The Prizmod and HUD select the matching variant. Source sprites are preserved in `sources/`; `tools/art/build_prizmod_icons.py` reproduces the palette-only adjustments without changing silhouette or transparency.

Run `python tools/art/build_prizmod_icons.py` with Pillow to regenerate. `prizmod-icons-preview.png` shows the current icons. The redrawn experiment was rejected and is not used by the game.
