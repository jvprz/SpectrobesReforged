# Comandi amministratore

I comandi richiedono **permesso livello 2 e un giocatore**: operatore o mondo con trucchi, non console diretta.

```text
/givespectrobe <species> [color]
/givespectrobe komainu
/givespectrobe segu 2
```

Crea un’entrata livello 1 con statistiche base e salute piena nel **deposito**. Colore 0, 1 o 2, predefinito 0. Equipaggiala poi nello slot infantile.

```text
/spectrobehealth
```

Ripristina la salute salvata dei sei slot squadra e dello slot infantile, non del deposito intero. Riponi e riequipaggia se serve aggiornare l’entità.

```text
/give @s spectrobesreforged:incubator
/give @s spectrobesreforged:white_prizmod
/give @s spectrobesreforged:komainu_fossil
```

Gli ultimi esempi sono comandi Minecraft. Non esiste un comando di evoluzione completata.
