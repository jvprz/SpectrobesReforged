# Über dieses Wiki

Handbuch zu **{{VERSION}}**, gestützt auf enthaltenen Code und Ressourcen. Datentabellen werden aus Definitionen erzeugt; Datapacks können das Verhalten ändern. Sechs Sprachen, Suche pro Ausgabe, helles/dunkles Design und Neuigkeiten sind enthalten.

Archivierte Ausgaben bewahren den Stand ihres ursprünglichen Commits **auf Englisch**, mit sichtbarem Hinweis und ohne neuere Mechaniken. Fanprojekt; Entwicklung, Analyse, Reinigung und Teamkampf bleiben unvollständig. Teste deinen Server oder dein Modpack vor dem Einsatz wichtiger Welten.
