# Comandos de administración

Los comandos del mod requieren **nivel de permiso 2** y una fuente de jugador: ejecútalos como operador o con trucos, no directamente desde la consola del servidor.

```text
/givespectrobe <species> [color]
/givespectrobe komainu
/givespectrobe segu 2
```

Crea una entrada de nivel 1, estadísticas base y vida completa en el **almacén**. El color opcional es 0, 1 o 2; por defecto 0. Equípala después en el hueco infantil.

```text
/spectrobehealth
```

Restaura la vida guardada del hueco infantil y los seis huecos del equipo, no del almacén completo. Si la entidad no refleja el cambio, guarda y vuelve a equipar la entrada.

Ejemplos de comandos de Minecraft para pruebas:

```text
/give @s spectrobesreforged:incubator
/give @s spectrobesreforged:white_prizmod
/give @s spectrobesreforged:komainu_fossil
```

No existe un comando de evolución completada.
