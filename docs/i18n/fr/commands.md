# Commandes administrateur

Ces commandes nécessitent le **niveau de permission 2 et un joueur** : opérateur ou monde avec commandes autorisées, pas la console serveur directe.

```text
/givespectrobe <species> [color]
/givespectrobe komainu
/givespectrobe segu 2
```

Crée une entrée niveau 1, statistiques de base et PV complets dans le **stockage**. Couleur 0, 1 ou 2, par défaut 0. Équipez ensuite l’enfant.

```text
/spectrobehealth
```

Restaure les PV sauvegardés des six emplacements d’équipe et de l’enfant, pas tout le stockage. Rangez puis rééquipez si nécessaire pour recréer l’entité.

```text
/give @s spectrobesreforged:incubator
/give @s spectrobesreforged:white_prizmod
/give @s spectrobesreforged:komainu_fossil
```

Ces derniers exemples sont des commandes Minecraft. Aucune commande d’évolution complète n’existe.
