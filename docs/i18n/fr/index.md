# Guide de l’explorateur

**Expérimental en 0.6.2-beta.3 :** le minerai donne un fossile brut à fouiller sur une table avant l’incubateur. Les anciens fossiles identifiés fonctionnent encore. Voir [l’essai de fouille](getting-started.md#excavation). Le tableau indique les résultats identifiés possibles.

Bienvenue dans **Spectrobes Reforged {{VERSION}}**, pour **Minecraft 1.21.1 et NeoForge**. Découvrez des [fossiles](fossils.md), réveillez vos compagnons dans l’[incubateur](awakening.md) et gérez votre collection avec le [Prizmod](prizmod.md).

Commencez par l’[installation et les recettes](getting-started.md), puis utilisez le [scanner](scanning.md), les [minéraux](minerals.md) et affrontez les [vortex Krawl](vortices.md). Six espèces enfants sont disponibles. L’évolution, l’analyse, le nettoyage et le combat en équipe restent en développement. Sauvegardez vos mondes avant une mise à jour bêta.
