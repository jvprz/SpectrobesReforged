# Scanner du compagnon

Équipez un enfant vivant dans le Prizmod, attendez son apparition, approchez-vous et pressez **R**. Le compagnon s’arrête **66 ticks**, environ **3,3 secondes**. Le centre est le compagnon, pas le joueur ; la recherche descend jusqu’à **64 blocs**.

Rayon horizontal : **6 blocs** pour Inkana, Komainu, Shakin et Spiko ; **8 blocs** pour Segu et Vilar. Les indices **orange** indiquent les fossiles, les **bleu clair** les minéraux. Maximum : **12 positions**, uniquement dans le terrain chargé. Le travail est réparti entre les ticks ; les résultats peuvent tarder. Les indices apparaissent dans l’air au-dessus du minerai. Le scanner ne mine pas. Sans résultat, vérifiez touche, emplacement enfant, PV, rayon et profondeur.
