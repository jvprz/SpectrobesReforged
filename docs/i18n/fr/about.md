# À propos du wiki

Guide de **{{VERSION}}** fondé sur le code et les ressources incluses. Les tableaux de données sont générés depuis les définitions ; les datapacks peuvent modifier le jeu. Six langues, recherche par édition, thèmes clair/sombre et nouveautés sont disponibles.

Les versions archivées sont conservées depuis leurs commits originaux **en anglais**, avec avertissement, sans ajout de mécaniques récentes. Projet de fans ; évolution, analyse, nettoyage et combat en équipe restent incomplets. Testez votre serveur ou modpack avant d’utiliser un monde important.
