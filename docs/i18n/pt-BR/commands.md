# Comandos de administrador

Os comandos exigem **permissão nível 2 e um jogador**: operador ou mundo com trapaças, não diretamente o console do servidor.

```text
/givespectrobe <species> [color]
/givespectrobe komainu
/givespectrobe segu 2
```

Cria uma entrada nível 1 com atributos base e vida cheia no **armazenamento**. Cor 0, 1 ou 2, padrão 0. Equipe depois no espaço infantil.

```text
/spectrobehealth
```

Restaura a vida salva dos seis espaços da equipe e do infantil, não de todo o armazenamento. Guarde e reequipe se precisar atualizar a entidade.

```text
/give @s spectrobesreforged:incubator
/give @s spectrobesreforged:white_prizmod
/give @s spectrobesreforged:komainu_fossil
```

Os últimos exemplos são comandos do Minecraft. Não existe comando de evolução concluída.
