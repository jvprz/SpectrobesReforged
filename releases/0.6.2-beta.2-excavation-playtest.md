# 0.6.2-beta.2 — Excavation playtest

Experimental build for feedback. Replace the previous JAR; do not install both. Requires Minecraft 1.21.1, NeoForge 21.1.219+, GeckoLib 4.8.3+ and Java 21. Use the same build on client and server.

Adds the DS-inspired surface opening, the ten Beyond the Portals tools in the main interface, six environment covers, visible stress/heat/gas, four persistent repairs, separate excavation skill, manual catalogue, Giga automation, confirmed 50/50 Blast, raw C/B/A/A+ mineral drops, debris animation and crown persistence through awakening. Existing in-progress specimens keep their grid and defaults for newly added state. Existing clean fossils and minerals still work.

Controls: three separate clicks to open the surface; hold/drag to work; 1 drill; 2 blower; R scanner; I toggles the inventory; ten tool icons surround the central working surface. Hover buttons for instructions. Recover/Giga/Blast use single clicks; Blast needs another click within five seconds. Extract at 90%, then collect the output.

The interface follows the ten-tool Beyond the Portals set. Earlier prototype-only tools remain supported internally for compatibility. The board remains sprite-based; adult evolution, custom parts, cubes, mystery stones, tool shops and microphone input are not implemented by this build.

[Detailed research, exact rules and test commands (Spanish)](excavacion-ds-investigacion-y-adaptacion.md).

Visual clarification: vanilla block textures for stone, soil and environment covers; pale loose dust with cursor hints; consumed specimens disappear from the working surface and show a failure notice and fragments. Failure/success outcomes survive table reloads; unfinished item progress remains saved.
