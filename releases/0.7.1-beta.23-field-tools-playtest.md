# Portable field tools playtest

- Drill: diamond-tier tool, 1.4× diamond mining speed, 1024 durability.
- Piton: diamond-tier 3×3 harvesting plane, sneak for precision, 1536 durability, normal per-block drops/wear/protection events.
- Blower: existing 5-block push retained. Blower S: wider 7-block cone, stronger push, removes snow layers within line of sight; 512 durability, two points per pulse.
- Fire drill: melts vanilla ice/snow, never auto-cleans frozen deposits; 384 durability, two points per operation.
- Water drill: 8-bucket persistent tank, absorbs sources, cools lava to obsidian/cobblestone and magma to basalt, extinguishes fire; sneak-use pours one bucket. 384 durability.
- Vacuum: persistent 16-bucket tank, drains water sources/waterlogged blocks, sneak-use pours one bucket; 512 durability.
- Recovery: hold 1.6 s to heal two player hearts, 24 uses and 30 s cooldown.
- Giga: one already manually catalogued specimen per activation, 85% integrity, eight wear, 256 durability. No manual XP or medals.
- Blast: reusable primed TNT with 3 s fuse; terrain effect limited to 2.5 blocks. Each affected deposit resolves once with independent 50% clean reward / 50% loss, 40–80% integrity. Eight wear per charge, 128 durability. No manual XP or medals. Existing block entities and protected blocks excluded.
- Ten expensive recipes and recipe-book unlocks; no prepared collectible materials are required. Vacuum uses sponge and hopper; elemental drills consume a drill; upgrades consume the normal blower. Virtual table tools remain independent.
- Descriptions in six mod languages, illustrated wiki recipes, offline vanilla ingredient models.
- Mutations run server-side after item-use snapshot transactions. Rejected water/block changes roll back before consuming tank/durability.
- Network protocol 13, wire schema unchanged; official release version stays 0.7.0-beta.
