# Buried deposits and Child scanner

- Pockets now start 5–9 blocks below the placement origin; every replaced host cell requires two intact cover blocks and closed, dry neighboring blocks. The complete placement is rejected before any writes if it would expose a surface/cave/cliff scar.
- Sandstone and red sandstone ores retain authored side PNGs and use the matching vanilla top/bottom textures, including legacy block models. No mod PNG was changed in this update.
- Shared ScanTargets classification fixes the incremental Child scan rejecting new elemental mineral blocks; renderer hints and actual search now use the same predicate.
- Offline wiki renderer includes the vanilla cube_bottom_top model and four vanilla sandstone face textures. Six-language docs updated.
- Existing chunks are not rewritten. Official version stays 0.7.0-beta; network protocol stays 12.
